# 狐伴 · Foxkin 🦊

一只会记住共同习惯的狐狸，陪你开始事情，也陪你结束一天。

[打开狐伴](https://foxkin.pages.dev/) · [产品方案](PRODUCT-PLAN.md)

## 可以做什么

- 10 / 25 / 45 分钟陪伴，暂停、恢复、延长或提前收工；也可以只来探望 1 分钟；探望没有倒计时，到想离开时再结束。
- 摸头、碰鼻子、狐狸表情、三个合成音乐电台、彩蛋和录制。
- 记住名字、欢迎表情、收工动作和三音旋律；第一次、通常回访与久别重逢有不同回应。
- 在第三、七个有确认结束记录的日期选择共同习惯。不要求连续、不按任务成果评分，同一天多次使用只算一个日子。
- 最近经历、本机自动快照、JSON 导出／恢复；旧版存档自动升级。
- 可选的加密自动备份和跨设备同步：在另一台设备输入同一私密同步码。
- 安装到桌面／主屏，离线加载狐狸和音乐；独立小窗，以及支持浏览器中的悬浮陪伴。
- 自动／省电／流畅三种画面设置，隐藏页面停止渲染，悬浮模式保留动画。

## 存档和同步

默认只保存在当前浏览器。每次已确认经历或习惯变化会保留最近三份本机快照；清理浏览器会同时清除这些快照，下载备份可以另行保管。

在「共同经历 → 自动备份与跨设备」开启云端备份。客户端生成 256 位私密同步码，用 AES-GCM 加密后上传；服务端保存密文和鉴权摘要，不保存解密钥匙。同步码只在自己的设备上输入，请私下保管；丢失后不能从服务端找回。

两端确认结束的经历按 ID 合并，名字／习惯同时修改时提示选择。正在进行的陪伴、静音和音量留在各自设备。页面打开期间及联网恢复时自动同步，关闭应用后不能产生新备份；离线修改留在本机，联网后再同步。其他设备删除云端存档后不会自动重新创建。

恢复 JSON 或自动快照会断开本机的云端连接，避免旧备份静默覆盖云端；云端备份本身仍保留。断开连接不删除数据，「删除云端备份」才会移除云端密文。本机存储失败、格式错误和多窗口竞争都有提示，不静默覆盖旧数据。

当前单份加密存档上限 1 MB。自动同步需要公网版或带 API 的开发服务器，纯静态服务器只能体验本地功能。

## 安装、离线和小窗

在「共同经历 → 入口与运行」安装或打开小窗。首次联网访问后，等待「离线资源已准备好」；模型、Three.js、解码器和图标全部缓存，字体使用系统字体。离线缓存不替代存档备份。

浏览器有自己的安装入口与限制；没有自动安装提示时，界面提供菜单操作说明。悬浮窗口使用 Document Picture-in-Picture，并提供独立小窗作为降级。悬浮视图支持暂停、继续、打招呼和返回收工；关闭小窗不结束陪伴。普通独立窗口不承诺置顶，同一存档由最新写入的窗口继续操作，其余窗口提示刷新。

更新完整资源包准备好后显示更新按钮；当前陪伴结束后才允许切换版本。这里提供的是可安装 Web 产品，没有独立的原生手机／桌面安装包。

## 开发

```sh
npm ci
npm run build
npm test
npx wrangler d1 execute foxkin-sync --local --file schema.sql
npx wrangler pages dev dist --ip 127.0.0.1 --port 8788
```

构建只是复制当前已使用的 Three.js 模块与资源，不引入前端框架。`dist/`、`vendor/`、测试输出和本地数据库不进入 Git。Three.js 固定为 0.186.1，构建资源中保留其 MIT 许可证。

不需要同步时，也可以在构建后用 `python3 -m http.server 8765 --bind 127.0.0.1` 预览源目录。运行 `python3 serve.py --port 8765 --api https://foxkin.pages.dev` 可将本地同步请求转给公网服务；仅绑定本机地址。

## 部署

Cloudflare Pages 从本仓库的 `main` 自动构建，构建命令 `npm ci && npm test && npm run build`，输出 `dist`。同步 API 使用 Pages Functions 与 D1 的 `DB` 绑定，表定义在 `schema.sql`，配置在 `wrangler.jsonc`。

首次部署到自己的账号时，创建 D1 数据库并替换配置中的 ID，再运行：

```sh
npx wrangler d1 execute foxkin-sync --remote --file schema.sql
npm run deploy
```

配置中的数据库 ID 不是访问密钥。不要提交 Cloudflare token、同步码、用户备份、本地数据库或测试存档。`FOX-FM-技术复盘.md` 和 `index.v1.html` 已明确排除。

## 验证与边界

`npm test` 检查计时／恢复、收工幂等、存档校验、日期成长、短时探望、重逢分类、加密／篡改检测、两端合并／冲突、本机计时隔离和云端删除。

浏览器验证覆盖 Chrome 的实际离线重载、小窗、悬浮、移动布局、跨设备连接与经历合并，也覆盖 WebKit 的移动触控配置、减弱动画、离线重载和悬浮降级。公网接口已检查鉴权、并发版本保护、格式拒绝与云端删除。另一次实际连续播放超过 30 分钟，经过三个电台切换，计时和音频调度持续工作，无页面异常；这不替代真人对音乐疲劳感的判断。真实 Windows Edge、macOS Safari、手机锁屏、系统休眠和音乐疲劳感需要对应设备与真人验证；浏览器自动化不能替代这些结论。

项目复用 [Foxwave · 狐狸电波](https://github.com/kobingogo/foxwave) 的模型、渲染与音乐，独立维护品牌、关系存档和后续玩法。
