# 狐伴 · Foxkin 🦊

一只会慢慢熟悉你的狐狸，陪你开始事情，也陪你结束一天。

Foxkin 是面向独自在电脑前工作、学习与创作的人设计的陪伴产品。名字中的 kin 表达亲近与归属，中文「狐伴」直接表达狐狸陪伴。

## 项目状态

这是一个独立新项目，包含可运行的 3D 互动与音乐起点，以及下一版产品方案。代码和模型复用自 [Foxwave · 狐狸电波](https://github.com/kobingogo/foxwave)，已更换品牌和浏览器存储键名。

当前已有：3D 狐狸、摸头与鼻子互动、表情、三种合成音乐电台、彩蛋和录制能力。

陪伴计时、收工选择、跨次见面的习惯记忆与共同经历记录尚未实现。它们是下一步开发目标，详见 [产品方案](PRODUCT-PLAN.md)。

## 第一个开发目标

做通一条体验：开始一次陪伴 → 收工时选择摸头或碰鼻子 → 保存选择 → 再次打开，狐狸主动邀请这个熟悉的招呼。

优先复用现有模型、表情与音频；先验证重逢体验，再增加第三与第七次习惯节点。首版采用桌面 Web。

## 本地运行

无需安装项目依赖，在项目目录运行：

```sh
cd /Users/bingo/workspace/foxkin
python3 -m http.server 8000
```

打开 http://localhost:8000 。通过 HTTP 访问，避免直接双击 HTML 导致模型加载失败。

Three.js、Draco 和字体从外部服务加载，需要网络连接；浏览器需支持 WebGL 和 Web Audio。当前版本尚未实现离线缓存。

## 文件

- `index.html`：可运行原型，包含界面、渲染、交互、音频与录制。
- `fox-web.glb`：复用的狐狸模型。
- `PRODUCT-PLAN.md`：竞品分析、核心循环、范围、平台选择与验证方案。

原项目的技术复盘、旧版页面及 Git 历史未带入本项目。本项目尚未创建 GitHub 仓库或部署地址。
