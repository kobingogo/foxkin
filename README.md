# 狐伴 · Foxkin 🦊

一只会慢慢熟悉你的狐狸，陪你开始事情，也陪你结束一天。

Foxkin 是面向独自在电脑前工作、学习与创作的人设计的陪伴产品。名字中的 kin 表达亲近与归属，中文「狐伴」直接表达狐狸陪伴。

## 项目状态

这是一个独立新项目，已实现第一条「陪伴—收工—重逢」体验，以及后续产品方案。代码和模型复用自 [Foxwave · 狐狸电波](https://github.com/kobingogo/foxwave)，已更换品牌和浏览器存储键名。

当前已有：3D 狐狸、摸头与鼻子互动、表情、三种合成音乐电台、彩蛋和录制能力。

现已实现：

- 10 / 25 / 45 分钟陪伴，可暂停、继续、提前结束，到期后可再陪 10 分钟。
- 音乐与陪伴计时独立，支持音量和安静陪伴。
- 收工时选择摸头或碰鼻子；下次打开，狐狸主动邀请这个熟悉的招呼。
- 狐狸名字、招呼偏好与共同经历保存到当前浏览器，并支持 JSON 备份和恢复。
- 刷新后确认恢复，关闭或长时间挂起期间不自动计入经历；重复收工不新增记录。

第三与第七次关系节点尚未实现，详见 [产品方案](PRODUCT-PLAN.md)。

## 当前验证目标

已做通一条体验：开始一次陪伴 → 收工时选择摸头或碰鼻子 → 保存选择 → 再次打开，狐狸主动邀请这个熟悉的招呼。

优先复用现有模型、表情与音频；先验证重逢体验，再增加第三与第七次习惯节点。首版采用桌面 Web。

## 本地运行

无需安装项目依赖，在项目目录运行：

```sh
cd /Users/bingo/workspace/foxkin
python3 -m http.server 8000
```

打开 http://localhost:8000 。通过 HTTP 访问，避免直接双击 HTML 导致模型加载失败。

Three.js、Draco 和字体从外部服务加载，需要网络连接；浏览器需支持 WebGL 和 Web Audio。当前版本尚未实现离线缓存。

## 检查

```sh
node companion.test.mjs
```

检查时间戳计时、暂停、恢复、收工幂等、习惯持久化与存档格式校验。

## 文件

- `index.html`：可运行原型，包含界面、渲染、交互、音频与录制。
- `companion.mjs`：会话计时、关系存档与恢复校验。
- `companion.test.mjs`：可直接运行的逻辑检查。
- `fox-web.glb`：复用的狐狸模型。
- `PRODUCT-PLAN.md`：竞品分析、核心循环、范围、平台选择与验证方案。

原项目的技术复盘、旧版页面及 Git 历史未带入本项目。本项目尚未创建 GitHub 仓库或部署地址。

## 当前边界

数据只保存在当前浏览器；清理浏览器或换设备前请下载备份。恢复备份会先校验，并在覆盖当前数据前提示。存储失败会明确显示提示，无法识别的原存档不会被自动覆盖。

当前提供最近 20 条经历的界面，备份保留全部记录。没有跨设备同步、PWA 离线缓存或系统提醒。浏览器验证目前以桌面 Chrome 和小屏布局为主；Safari、Edge、系统休眠和长时音频仍需真实设备验证。
